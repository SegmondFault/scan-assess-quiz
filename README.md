# Python Quiz App

This web app runs a quiz based on JSON question files generated by different modules.

```bash
uv sync
uv run main.py
```

## scan-assess module controls

This project can be embedded as a scan-assess module control surface. The
`module_controls.json` file declares the same kind of GUI-launchable controls
used by other scan-assess modules, so the parent GUI can discover how to start
the quiz without hardcoding quiz-specific behaviour.

When the quiz is completed it writes a Markdown report and a paired JSON report.
The scan-assess quiz module can copy those files into a scan-assess run so the
LLM receives structured user-context telemetry.
